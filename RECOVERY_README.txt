PCIA RECOVERED WORKING BASE — v0.5

This folder was selected from DPCIA_OLD because:
- app.py is present and passes Python syntax validation.
- It is the same v0.5 build previously shown running successfully in the browser.
- It contains the saved SQLite database and the Pubali Abashon Notesheet/Sanction master files.
- It has the broadest working route set before the later guided-workstation changes.

Install:
1. Rename existing D:\PCIA to D:\PCIA_BROKEN_<date>.
2. Extract this package and rename the extracted folder to D:\PCIA.
3. Double-click START_PCIA.cmd.
4. Double-click STOP_PCIA.cmd to stop only the server using port 5050.

This is the last confirmed working UI base. It does not yet guarantee correct automatic replacement of all master-proforma variables.
